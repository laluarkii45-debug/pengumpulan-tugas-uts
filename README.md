Judul dan Tujuan ProyekProyek ini adalah studi Machine Learning (Pembelajaran Mesin) untuk prediksi status akademik mahasiswa (apakah seorang mahasiswa akan Lulus atau Gagal berdasarkan data sosiodemografi, jarak tempat tinggal, tingkat kehadiran, dan aktivitas e-learning).   Variabel Target (label (fail=1, pass=0)):0 = Lulus1 = Gagal2. Struktur dan Alur Kerja Proyek (Pipeline)Berdasarkan sel-sel kode yang dijalankan, alur kerja proyek ini meliputi:Impor Pustaka (Library):
Menggunakan pustaka standar Python untuk analisis data dan pemodelan, seperti pandas, numpy, matplotlib, seaborn, serta scikit-learn (untuk preprocessing, pemodelan klasifikasi seperti Logistic Regression, Decision Tree, Random Forest, serta evaluasi metrik).   Pemuatan Data (Data Loading):
Membaca dataset dari file bernama original.csv yang memiliki dimensi awal 87 baris dan 22 kolom.   Eksplorasi dan Pembersihan Data Awal (EDA & Data Cleaning):Pemeriksaan tipe data (semuanya bertipe numerik/float).   Pemeriksaan missing value (ditemukan beberapa kolom yang memiliki nilai kosong/NaN, serta beberapa kolom kosong yang tidak terpakai seperti Unnamed: 20 dan Unnamed: 21).   Pembersihan data awal menghapus baris/kolom kosong dan memeriksa duplikat (dimensi akhir data bersih menjadi 80 baris dan 20 kolom).   Analisis Target (Distribusi Kelas):Lulus (0): 68 mahasiswa (85%)   Gagal (1): 12 mahasiswa (15%)   Catatan dari notebook: Distribusi kelas menunjukkan ketidakseimbangan (imbalanced class) karena jumlah mahasiswa yang lulus jauh lebih mendominasi daripada yang gagal.   Visualisasi dan Statistik Deskriptif:Menampilkan ringkasan statistik (rata-rata, standar deviasi, nilai minimum/maksimum) untuk setiap fitur.   Membuat histogram untuk fitur-fitur numerik (seperti umur, jarak ke universitas, jumlah login ke area modul, total jam belajar, dan persentase kehadiran).   3. Fitur-Fitur Utama dalam DatasetDataset ini mencakup berbagai variabel prediktor, di antaranya:Demografi & Latar Belakang: Gender, Age, POLAR4/3 Quintile, Adult HE Quintile, TUNDRA Quintile, Gaps GCSE Quintile (faktor sosiodemografi dan wilayah pendidikan).
